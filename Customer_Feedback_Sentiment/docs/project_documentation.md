# Project Documentation — Customer Feedback Sentiment

## 1. Introduction
Customer feedback contains useful information about customer satisfaction. Sentiment analysis can automatically organize feedback into positive, neutral, and negative categories.

## 2. Objective
To clean customer feedback, analyze sentiment patterns, visualize the results, and build a machine-learning model that predicts the sentiment of new feedback.

## 3. Scope
The project covers text preprocessing, exploratory analysis, visualizations, classification, model evaluation, and dashboard preparation.

## 4. Data Description
The dataset contains a review ID, customer feedback text, and sentiment label. A dummy dataset is used for this implementation.

## 5. Methodology
1. Load the dataset.
2. Clean and normalize feedback text.
3. Examine sentiment distribution.
4. Create visualizations.
5. Split data into training and testing sets.
6. Convert text into TF-IDF features.
7. Train Logistic Regression.
8. Evaluate predictions using accuracy, classification report, and confusion matrix.
9. Export predictions for dashboard use.

## 6. Expected Outputs
- Sentiment distribution chart
- Review-length analysis chart
- Confusion matrix
- Prediction CSV
- Model performance report
- Power BI dashboard

## 7. Conclusion
The project demonstrates an end-to-end customer feedback sentiment workflow, from data preparation through visualization and machine-learning prediction.
